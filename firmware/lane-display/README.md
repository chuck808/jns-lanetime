# Lane result display

LN-1, LN-2, LN-3, and LN-4 share this target with configured lane identity. These are separate from the small lane-identification screens on sensors. Receive matching results and control updates, display time/rep and non-result states, and handle stale output. No application transmissions are planned.

Implementation has not started. See [build specification](../../docs/build-specification.md).
