# Hardware

Reserved for priced parts lists, wiring, pin assignments, PCB work, and enclosure files once components are selected.

Prototype resources available: Bambu Lab P1S printer and Fusion 360. Integrated ESP32 development boards with screens/buttons are candidates, not selected parts.

Optical requirement: 940 nm IR with 38 kHz modulation. Each active retroreflective head requires both transmitter and receiver. Emitter drive and receiver carrier/burst compatibility remain to be specified from selected components.

Current [mock-ups](../images/README.md) establish appearance and device roles only. No dimensions, schematic, PCB, or manufacturing CAD are supplied yet.
